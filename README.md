# WateefyElectronics

Collection of documentation, datasheets, marketing information, and WLED
firmware links for Wateefy Electronics LED pixel controllers.

## Repository contents

- [Documentation](documentation/README.md) - setup guides, wiring notes, FAQs,
  and controller usage information
- [Datasheets](datasheets/README.md) - controller, component, power, and
  connector reference material
- [Marketing](marketing/README.md) - product overviews, sell sheets, images,
  and launch copy
- [Firmware](firmware/README.md) - WLED links, flashing resources, and custom
  firmware references

## WLED firmware resources

- [WLED project site](https://kno.wled.ge/)
- [WLED web installer](https://install.wled.me/)
- [WLED GitHub releases](https://github.com/Aircoookie/WLED/releases)
- [WLED source repository](https://github.com/Aircoookie/WLED)

## Using this repository

Use the folders above to organize product material by purpose:

- Put user-facing guides and reference material in `documentation/`
- Store PDFs and technical references in `datasheets/`
- Keep brochures, product copy, and other sales assets in `marketing/`
- Track firmware links, release notes, and controller-specific flashing details
  in `firmware/`
